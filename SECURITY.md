# Security policy

Do not include credentials, private keys, production host inventories, ACME
state, Docker registry configuration, or service logs in issues or pull
requests.

For a suspected vulnerability, use GitHub's private security-advisory reporting
for this repository. If that channel is unavailable, use the contact route at
[nim.zone](https://nim.zone) rather than opening a public issue.

This project controls high-trust Docker Swarm surfaces. Keep browser mutations
disabled until the documented production prerequisites and live verification
checks have passed.
