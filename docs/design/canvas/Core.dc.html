Move this controller

The controller can live anywhere — a node, a laptop, a box that has never seen Docker. Moving it moves the state with it.

1
Prepare the target
Run the core installer there in standby mode. It starts with no cluster and cannot act.
2
Copy the sealed state
A single encrypted file plus its key, taken at the moment this one is fenced.
3
Promote the target
This one stops accepting work; that one takes the next authority term.
Prepare a target
There is no automatic failover, and SwarmOps will not pretend otherwise. Two active controllers would both believe they own the cluster, so a move is a deliberate act with a fence in the middle of it.
